# Networking Topologies — Key Points

## What It Is

- A **network topology** is the typical arrangement and physical or logical connection of devices in a network.
- Computers (hosts) — clients and servers — actively use the network; network components such as switches, bridges, and routers have a distribution function and ensure all hosts can establish a logical connection with each other.
- The topology determines which components are used and the access methods to the transmission media.
- **Physical topology**: the layout of the transmission medium used to connect devices. For conductive or glass fiber media this means the cabling plan, the positions of the nodes, and the connections between nodes and cabling.
- **Logical topology**: how the signals act on the network media, i.e. how data is transmitted across the network from one device to the devices' physical connection.

- Node types: **Repeaters, Hubs, Bridges, Switches, Router/Modem, Gateways, Firewalls**.
- Network nodes are the transmission medium's connection points to transmitters and receivers of electrical, optical, or radio signals in the medium.
- A node may be connected to a computer, but certain types may have only a microcontroller — or no programmable device at all.

### 3. Classifications

- A topology can be imagined as a virtual form or structure of a network; this form does not necessarily correspond to the actual physical arrangement of the devices.
- Therefore topologies can be either **physical or logical** — e.g. computers on a LAN may be physically arranged in a circle in a bedroom, but it is very unlikely to be an actual ring topology.

- More complex networks can be built as **hybrids** of two or more of these basic topologies.

## Point-to-Point

- The simplest topology: a dedicated connection between exactly two hosts, with a direct physical link only between them.
- Both devices use that connection for mutual communication.
- It is the basic model of traditional telephony.
- Must **not** be confused with **P2P (Peer-to-Peer architecture)**.

## Bus

- All hosts are connected via one shared transmission medium — for example a coaxial cable.
- Every host has access to the transmission medium and to all signals transmitted over it.
- There is **no central network component** controlling the processes on it.
- Because the medium is shared, only one host can send at a time; all others can only receive, evaluate the data, and check whether it is intended for them.

## Star

- A central network component maintains a connection to all hosts, each host connected via a separate link.
- The central component is usually a **router, hub, or switch**, which handles the forwarding function: data packets are received and forwarded to the destination.
- Data traffic on the central component can be very high, since all data and connections go through it.

## Ring

- In a **physical ring**, each host/node is connected to the ring with two cables: one for incoming signals and one for outgoing signals — one cable arrives at each host and one leaves.
- A ring typically requires **no active network component**; control and access to the transmission medium are regulated by a protocol all stations adhere to.
- A **logical ring** is based on a physical star topology, where a distributor at the node simulates the ring by forwarding from one port to the next.
- Information is transmitted in a predetermined transmission direction.
- The medium is typically accessed sequentially from station to station using a retrieval system from the central station or a **token**.
- A **token** is a bit pattern that continually passes through the ring network in one direction, working according to the claim token process.

## Mesh

- In meshed networks, many nodes decide about the connections on a physical level and the routing on a logical level — so meshed structures have **no fixed topology**.
- Two basic structures: **fully meshed** and **partially meshed**.
- **Fully meshed**: each host is connected to every other host. Primarily used in **WAN or MAN** to ensure high reliability and bandwidth.
- Important network nodes such as routers can be networked together this way: if one router fails, the others continue working and the network absorbs the failure thanks to the many connections.
- Each node of a fully meshed topology has the same routing functions and knows its neighboring nodes, their proximity to the network gateway, and traffic loads.
- **Partially meshed**: endpoints are connected by only one connection — specific nodes connect to exactly one other node, while some others connect to two or more nodes via point-to-point connections.

## Tree

- The tree topology is an **extended star topology**, used by more extensive local networks — especially useful when several topologies are combined.
- Often used in larger company buildings.
- There are logical tree structures (according to the **spanning tree**) as well as physical ones.
- Modular modern networks based on structured cabling with a **hub hierarchy** also have a tree structure.
- Tree topologies are also used for broadband networks and city networks (**MAN**).

## Hybrid

- Hybrid networks combine two or more topologies so that the resulting network does not present any standard topology.
- Example: a tree network can represent a hybrid topology in which star networks are connected via interconnected bus networks.
- However, a tree network linked to another tree network is still topologically a **tree** network.
- A hybrid topology is always created when two **different** basic topologies are interconnected.

## Daisy Chain

- Multiple hosts are connected by running a cable from one node to another, creating a chain of connections.
- Also known as a daisy-chain configuration, in which multiple hardware components are connected in **series**.
- Often found in automation technology (**CAN**).
- Daisy chaining is based on the **physical arrangement** of the nodes — in contrast to token procedures, which are structural and can be made independent of the physical layout.
- The signal is sent to and from a component via its previous nodes to the computer system.

## Acronyms

- **CAN**: Controller Area Network (automation technology bus)
- **LAN**: Local Area Network
- **MAN**: Metropolitan Area Network
- **NIC**: Network Interface Controller
- **P2P**: Peer-to-Peer
- **WAN**: Wide Area Network

## Definitions

- **Physical topology**: the actual layout of the transmission medium — cabling plan, node positions, and the connections between nodes and cabling.
- **Logical topology**: how signals act on the media, i.e. the path data takes across the network regardless of physical wiring.
- **Node**: a connection point of the transmission medium to transmitters and receivers of electrical, optical, or radio signals.
- **Token**: a bit pattern that continually circulates a ring network in one direction, granting the holder the right to transmit (claim token process).
- **Spanning tree**: the logical tree structure used to organize a network without loops.
- **Fully meshed**: every host connected to every other host — maximum redundancy and bandwidth.
- **Partially meshed**: only some nodes have multiple connections; others attach via a single point-to-point link.
