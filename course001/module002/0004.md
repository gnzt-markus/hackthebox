# Network Communication — Key Points

## What It Is

- Three components are essential for network communication: MAC addresses, IP addresses, and ports.
- Together they ensure data is correctly sent and received between devices across local and global networks.

## MAC Addresses

- A unique identifier assigned to a device's NIC, operating at the Data Link Layer (Layer 2).
- 48 bits long, shown in hexadecimal (e.g., 00:1A:2B:3C:4D:5E); first 24 bits identify the manufacturer (OUI), last 24 bits identify the device.
- Used to deliver data frames to the correct physical device within a LAN; switches forward frames based on destination MAC address.
- Address Resolution Protocol (ARP) maps IP addresses to MAC addresses, bridging logical and physical addressing.
- Example: Computer A uses ARP to learn Computer B's MAC address, then sends a frame that the switch forwards to the correct port.

## IP Addresses

- A numerical label assigned to each device using the Internet Protocol, operating at the Network Layer (Layer 3).
- IPv4: 32-bit address space, formatted as four decimal numbers (e.g., 192.168.1.1).
- IPv6: 128-bit address space, formatted as eight groups of hexadecimal digits, created to address IPv4 exhaustion.
- Routers use IP addresses to determine the best path across networks; unlike MAC addresses, IPs can change based on topology/policy.

## Ports

- A number assigned to specific processes/services, operating at the Transport Layer (Layer 4) with TCP/UDP.
- Allow multiple services to run simultaneously on one IP address by distinguishing traffic per application.
- Range from 0 to 65535, divided into three categories.
- Well-Known Ports (0–1023): reserved for standard services managed by IANA (e.g., HTTP on port 80, HTTPS on port 443, FTP on ports 20/21).
- Registered Ports (1024–49151): assigned to specific vendor services (e.g., Microsoft SQL Server on port 1433), less strictly regulated.
- Dynamic/Private Ports (49152–65535): ephemeral ports randomly chosen by the client OS for temporary sessions.

## Browsing the Internet Example

- DNS Lookup: the domain name is resolved to an IP address.
- Data Encapsulation: the browser's HTTP request is wrapped in TCP (specifying port 80/443) and IP; ARP finds the gateway's MAC address.
- Data Transmission: the frame is sent to the router's MAC address, then forwarded hop-by-hop based on the destination IP.
- Server Processing: the server receives the packet, directs it to the listening application, and processes the request.
- Response Transmission: the server replies to the client's temporary port, and the response travels back through the network to the client.

## Acronyms

- **OUI**: Organizationally Unique Identifier
- **ARP**: Address Resolution Protocol
- **PDU**: Protocol Data Unit
- **IANA**: Internet Assigned Numbers Authority

## Definitions

- PDU **Frame** (OSI Layer 2: Data Link Layer) ≈ PDU **Packet** (OSI Layer 3: Network Layer) ≈ PDU **Segment**[TCP]/**Datagram**[UDP] (OSI Layer 4: Transport Layer)

## Q&A – Questions and Answers

**Q: What protocol maps IP addresses to MAC addresses?**

**A**: ARP

**Q: Which IP version uses 128-bit addressing?**

**A**: IPv6

**Q: At which layer of the OSI model do ports operate?**

**A**: Transport Layer

**Q: What is the designated port number for HTTP?**

**A**: 80

**Q: What is the first step in the process of a web browsing session?**

**A**: DNS Lookup
