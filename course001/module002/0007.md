# Domain Name System (DNS) — Key Points

## What It Is

- DNS acts like the phonebook of the internet, translating human-readable domain names (e.g., www.google.com) into numerical IP addresses.
- Without DNS, users would need to memorize complex IP addresses for every website they want to visit.

## Domain Names vs. IP Addresses

- Domain Name: a readable address like www.example.com that people can easily remember.
- IP Address: a numerical label (e.g., 93.184.216.34) that uniquely identifies a device on a network.
- DNS bridges the gap between these two, allowing users to type a domain name instead of an IP address.

## DNS Hierarchy

- DNS is organized like a tree, starting from the root and branching into different layers.
- Root Servers: the top of the DNS hierarchy.
- Top-Level Domains (TLDs): such as .com, .org, .net, or country codes like .uk, .de.
- Second-Level Domains: for example, "example" in example.com.
- Subdomains or Hostname: for instance, "www" in www.example.com, or "accounts" in accounts.google.com.

## DNS Resolution Process

- The browser is given a domain name, and the computer needs to resolve it to the corresponding IP address.
- The computer first checks its local DNS cache to see if the IP address is already known.
- If not found locally, it queries a recursive DNS server, often provided by an ISP or a third-party service like Google DNS.
- The recursive DNS server contacts a root server, which points it to the appropriate TLD name server.
- The TLD name server directs the query to the authoritative name server for the domain.
- The authoritative name server responds with the correct IP address.
- The recursive server returns this IP address to the computer, allowing it to connect directly to the website's server.
- This entire process typically completes within fractions of a second.

## Acronyms

- **DNS**: Domain Name System
- **TLD**: Top-Level Domain
- **ISP**: Internet Service Provider

## Q&A – Questions and Answers

**Q: What type of domain is `.com` considered as? (Format: Three words, example: One-Two Three)**

**A**: Top-level Domain

**Q: In the domain `www.example.com`, what is `example` called?**

**A**: Second-level Domain

**Q: What is checked first in the DNS resolution process when you enter a domain name into a browser? (Format: Two words)**

**A**: DNS cache

**Q: What type of DNS server is typically provided by an Internet Service Provider?**

**A**: Recursive DNS server

**Q: Which server directs the recursive DNS server to the appropriate TLD name server?**

**A**: Root server

**Q: What numerical label uniquely identifies a device on a network?**

**A**: IP address

**Q: In the URL "accounts.google.com", what is `accounts` considered as?**

**A**: Subdomain
