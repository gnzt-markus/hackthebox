# Dynamic Host Configuration Protocol (DHCP) — Key Points

## What It Is

- DHCP is a network management protocol that automates assigning IP addresses and other configuration parameters to devices.
- It removes the need for manual IP configuration, which is slow and error-prone, especially in large networks.
- Parameters delivered include IP address, subnet mask, default gateway, and DNS servers.

## Why It's Useful

- Reduces administrative workload by automatically assigning unique IP addresses.
- Prevents IP address conflicts and duplication across the network.
- Recycles IP addresses no longer in use when devices disconnect, optimizing the available address pool.

## Roles

- DHCP Server: a network device (router or dedicated server) that manages IP address allocation and maintains a pool of addresses and configuration parameters.
- DHCP Client: any device that connects to the network and requests configuration parameters from the DHCP server.

## The DORA Process

- DORA stands for Discover, Offer, Request, Acknowledge — the four-step exchange between client and server.
- Discover: the client broadcasts a DHCP Discover message to locate available DHCP servers.
- Offer: DHCP servers respond with a DHCP Offer message, proposing an IP address lease.
- Request: the client replies with a DHCP Request message, accepting the offered address.
- Acknowledge: the server sends a DHCP Acknowledge message, confirming the assignment so the client can start communicating.

## Lease Time and Renewal

- Assigned IP addresses are not permanent; they are issued with a specific lease time (e.g., 24 hours).
- Before the lease expires, the client proactively sends a renewal request to the DHCP server.
- If the server approves, it responds with a DHCP Acknowledge message, extending the lease.

## Example Scenario

- Alice connects a new laptop to the office network without an IP address.
- The laptop sends a DHCP Discover message; the office DHCP server offers the address 192.168.1.10.
- The laptop sends a DHCP Request to accept, and the server confirms with a DHCP Acknowledge.
- Before the lease expires, the laptop sends another request to renew it, and the server extends the lease via acknowledgment.

## Acronyms

- **DHCP**: Dynamic Host Configuration Protocol
- **DORA**: Discover, Offer, Request, Acknowledge
