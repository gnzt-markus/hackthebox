# Network Security — Key Points

## What It Is

- Network security refers to measures taken to protect data, applications, devices, and systems within a network from unauthorized access or damage.
- The goal is to uphold the CIA triad: confidentiality (only authorized users can view data), integrity (data remains accurate and unaltered), and availability (network resources are accessible when needed).
- Two critical components discussed are Firewalls and Intrusion Detection/Prevention Systems (IDS/IPS).

## Firewalls

- A firewall is a network security device (hardware, software, or both) that monitors incoming and outgoing traffic and enforces rules (firewall policies/access control lists) to allow or block it.
- Firewalls filter traffic based on factors like IP addresses, port numbers, and protocols, and can log events and generate alerts on suspicious activity.
- Packet Filtering Firewall: operates at Layer 3/4 of the OSI model, examining source/destination IP, port, and protocol.
- Stateful Inspection Firewall: tracks the state of connections and understands the entire conversation, not just individual packets.
- Application Layer Firewall (Proxy Firewall): operates up to Layer 7, inspecting actual traffic content (e.g., HTTP requests) to block malicious ones.
- Next-Generation Firewall (NGFW): combines stateful inspection with advanced features like deep packet inspection, intrusion detection/prevention, and application control.
- In homes, the firewall is often built into the router/modem; in larger networks, it's typically a separate device placed between the modem/router and the internal network.

## Intrusion Detection and Prevention Systems (IDS/IPS)

- An IDS observes traffic/system events to identify malicious behavior or policy violations and generates alerts, but does not block traffic.
- An IPS works like an IDS but additionally prevents or rejects malicious traffic in real time.
- Both use signature-based detection (matching traffic against known exploit databases) and anomaly-based detection (identifying unusual activity compared to normal patterns).
- Network-Based IDS/IPS (NIDS/NIPS): hardware or software placed at strategic network points to inspect all passing traffic.
- Host-Based IDS/IPS (HIDS/HIPS): runs on individual hosts, monitoring traffic and system logs for suspicious behavior on that specific machine.
- IDS/IPS can be placed behind the firewall, in the DMZ (Demilitarized Zone) to monitor traffic to/from publicly accessible servers, or directly on endpoint devices.

## Best Practices

- **Define Clear Policies**: Define clear, consistent firewall policies based on the principle of least privilege (only allow what is necessary).
- **Regular Updates**: Regularly update firewalls, IDS/IPS signatures, and operating systems to defend against new threats.
- **Monitor and Log Events**: Monitor and log firewall, IDS/IPS, and system events to catch suspicious patterns early.
- **Layered Security**: Apply layered security (defense in depth) using multiple measures like firewalls, IDS/IPS, antivirus, and endpoint protection.
- **Periodic Penetration Testing**: Conduct periodic penetration testing to verify the effectiveness of security policies and devices.

## Acronyms

- **CIA (triad)**: Confidentiality, Integrity, Availability
- **IDS**: Intrusion Detection System
- **IPS**: Intrusion Prevention System
- **NGFW**: Next-Generation Firewall
- **NIDS/NIPS**: Network-Based IDS/IPS
- **HIDS/HIPS**: Host-Based IDS/IPS
- **DMZ**: Demilitarized Zone
- **OSI**: Open Systems Interconnection
- **ACL**: Access Control List

## Definitions

- **Defense in depth** is a cybersecurity strategy that uses multiple layers of security controls to protect data and systems. Instead of relying on a single barrier, it stacks different defenses—like physical locks, firewalls, and user passwords—so that if one layer fails, another stops the threat

## Q&A – Questions and Answers

**Q: What device monitors network traffic and enforces rules to allow or block specific traffic?**

**A**: Firewall

**Q: Which type of firewall operates at the network and transport layers of the OSI model? (Format: two words)**

**A**: Packet filtering

**Q: What advanced feature does a Next-Generation Firewall include beyond stateful inspection? (Format: three words)**

**A**: Deep packet inspection

**Q: Which system generates alerts for suspicious network activity without blocking it? (Format: acronym)**

**A**: IDS

**Q: Which system not only detects but also prevents suspicious network activity by blocking it? (Format: acronym)**

**A**: IPS

**Q: What detection method involves comparing network traffic against a database of known exploits? (Format: three words)**

**A**: Signature-based detection
