# Wireless Networks — Key Points

## What It Is

- A wireless network uses radio waves or other wireless signals to connect devices like computers, smartphones, and IoT gadgets without physical cables.
- It allows devices to connect to the internet, share files, and access services over the air.
- Advantages: mobility, ease of installation (no extensive cabling), and easier scalability than wired networks.
- Disadvantages: interference from walls/electronics/atmospheric conditions, higher security risks if unprotected, and generally slower speeds than comparable wired connections.

## Wireless Router

- A router forwards data packets between computer networks.
- In a home or small office, a wireless router combines routing (directing data to the correct destination) with acting as a wireless access point (providing Wi-Fi coverage).
- It connects to a modem that brings internet service from the ISP.
- Main components: WAN port (connects to the internet source), LAN ports (for wired local devices), antennae (transmit/receive wireless signals), and a processor/memory (handle routing and network management).

## Mobile Hotspot

- A mobile hotspot lets a smartphone share its cellular data connection via Wi-Fi so other devices can connect to it like a regular Wi-Fi network.
- It uses cellular data (e.g., 4G or 5G) to connect devices to the internet.
- Typical range is only a few meters, and running a hotspot can significantly drain battery.
- Access is usually password-protected, similar to home Wi-Fi security.

## Cell Tower

- A cell tower (cell site) holds antennas and communications equipment to create a cellular network cell, i.e., the coverage area of that tower.
- Towers use radio transmitters/receivers with antennas to communicate over specific frequencies.
- A Base Station Controller (BSC) manages multiple towers and handles handoffs of calls/data as users move between cells.
- Towers connect to the core network via backhaul links, typically fiber optic or microwave.
- Macro cells are large towers covering several kilometers, ideal for rural areas; micro/small cells are smaller installations in dense urban areas filling coverage gaps.

## Frequencies in Wireless Communications

- Wireless communications use radio waves emitted at specific frequencies (oscillation rates), measured in hertz (Hz).
- 2.4 GHz: used by older Wi-Fi standards (802.11b/g/n); better wall penetration but more prone to interference (e.g., microwaves, Bluetooth).
- 5 GHz: used by newer Wi-Fi standards (802.11a/n/ac/ax); faster speeds but shorter range.
- Cellular bands: used for 4G (LTE) and 5G, ranging from lower frequencies (700 MHz) to higher 5G frequencies (up to 28 GHz and beyond).
- Lower frequencies travel farther but carry less data; higher frequencies carry more data but have shorter range.
- Frequency bands can become congested, causing interference; government agencies (e.g., the FCC) regulate frequency allocations to manage this.

## Summarizing

- A wireless router provides home internet access via Wi-Fi at 2.4 GHz and 5 GHz frequencies.
- Phones automatically connect via the nearest cell tower using 4G or 5G when away from home.
- A mobile hotspot can share cellular data with other devices, e.g., while traveling.
- Three key wireless technologies are used day-to-day: Wi-Fi for local access, cellular networks for wide-area coverage, and mobile hotspots for personal data sharing.

## Acronyms

- **ISP**: Internet Service Provider
- **WAN**: Wide Area Network
- **LAN**: Local Area Network
- **BSC**: Base Station Controller
- **LTE**: Long-Term Evolution
- **FCC**: Federal Communications Commission
