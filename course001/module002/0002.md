# Network Concepts — Key Points

## What It Is

- Networking underpins nearly all modern technology (consumer electronics, multimedia, hardware, software, firmware), built on top of the TCP/IP stack.
- This section covers the OSI and TCP/IP models, common network protocols, and transmission methods used to move data across networks.

## OSI Model (7 Layers)

- A conceptual framework standardizing telecom/computing functions into seven abstract layers, helping vendors build interoperable devices and software.
- **Physical (Layer 1)** – transmits raw bitstreams over physical media (cables, hubs, repeaters).
- **Data Link (Layer 2)** – node-to-node data transfer with error detection/correction; uses MAC addresses; switches/bridges operate here.
- **Network (Layer 3)** – packet forwarding/routing and logical addressing via IP addresses; routers operate here.
- **Transport (Layer 4)** – end-to-end communication, segmentation, flow control; TCP (reliable) and UDP (fast, connectionless) operate here.
- **Session (Layer 5)** – establishes, maintains, and terminates sessions between applications; supports checkpointing/recovery.
- **Presentation (Layer 6)** – translates data format between systems; handles encryption/decryption and compression.
- **Application (Layer 7)** – provides network services directly to end-user apps; includes HTTP, FTP, SMTP, DNS.

## File Transfer Example (OSI Walkthrough)

- Application layer initiates the transfer → Presentation layer encrypts the file → Session layer establishes the connection → Transport layer segments the data → Network layer determines the route → Data Link layer frames the data → Physical layer transmits the raw bits.

## TCP/IP Model (4 Layers)

- A condensed, practical version of the OSI model used for real-world internet implementation.
- **Link Layer** – handles physical hardware/media (Ethernet, Wi-Fi); corresponds to OSI's Physical + Data Link layers.
- **Internet Layer** – logical addressing and routing (IP, ICMP); corresponds to OSI's Network layer.
- **Transport Layer** – end-to-end communication via TCP/UDP; corresponds to OSI's Transport layer.
- **Application Layer** – protocols like HTTP, FTP, SMTP; corresponds to OSI's Session + Presentation + Application layers.

## OSI vs. TCP/IP

- TCP/IP simplifies OSI by merging layers, making it more application-oriented and practical for internet communication.
- TCP/IP is the actively implemented backbone of network data transmission.
- OSI is a theoretical framework used to conceptually understand and structure network operations.
- Together, they bridge theory and practical application.

## Website Access Example (TCP/IP Walkthrough)

- Application layer: browser uses HTTP to request the webpage.
- Transport layer: TCP ensures reliable data transfer.
- Internet layer: IP routes packets to the web server.
- Link layer: data is physically transmitted over the network.

## Common Network Protocols

- HTTP – transfers web pages (Application Layer).
- FTP – transfers files between systems (Application Layer).
- SMTP – handles email transmission (Application Layer).
- TCP – reliable, connection-oriented data delivery (Transport Layer).
- UDP – fast, connectionless delivery without guaranteed reliability (Transport Layer).
- IP – routes packets across network boundaries (Internet Layer).

## Transmission

**Transmission Types**
- Analog – continuous signals (e.g., traditional radio).
- Digital – discrete signals/bits (e.g., computer networks, digital telephony).

**Transmission Modes**
- Simplex – one-way only (e.g., keyboard to computer).
- Half-duplex – two-way, but not simultaneous (e.g., walkie-talkies).
- Full-duplex – two-way, simultaneous (e.g., phone calls).

**Transmission Media**
- Wired – twisted pair (Ethernet/LAN), coaxial (cable TV, early Ethernet), fiber optic (high-speed internet backbones).
- Wireless – radio waves (Wi-Fi, cellular), microwaves (satellite), infrared (short-range, e.g., remote controls).

## Acronyms

- **OSI**: Open Systems Interconnection
- **HTTP**: Hypertext Transfer Protocol
- **FTP**: File Transfer Protocol
- **SMTP**: Simple Mail Transfer Protocol
- **TCP**: Transmission Control Protocol
- **UDP**: User Datagram Protocol
- **IP**: Internet Protocol
- **ICMP**: Internet Control Message Protocol
- **LAN**: Local Area Network
- **MAC**: Media Access Control
- **DNS**: Domain Name System

## Q&A – Questions and Answers

**Q: What layer of the OSI model is responsible for physical connections like Ethernet cables?**

**A**: Physical Layer

**Q: Name the OSI layer that deals with logical addressing and routing.**

**A**: Network Layer

**Q: Which protocol ensures reliable delivery of data and operates at the Transport Layer?**

**A**: TCP

**Q: At what layer do switches operate within the OSI model?**

**A**: Data Link Layer

**Q: What layer of the TCP/IP model corresponds to the OSI model’s Application, Presentation, and Session layers?**

**A**: Application Layer

**Q: Which layer of the OSI model manages data encryption and data format conversion?**

**A**: Presentation Layer

**Q: Name a protocol used for web browsing that operates at the Application Layer.**

**A**: HTTP

**Q: Which OSI layer ensures the segments are transferred reliably and in sequence?**

**A**: Transport Layer

**Q: Which protocol provides fast, connectionless communication and operates at the Transport Layer?**

**A**: UDP
