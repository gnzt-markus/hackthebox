# Network Address Translation (NAT) — Key Points

## What It Is

- NAT is a solution to IPv4 address scarcity that allows multiple devices on a private network to share a single public IP address.
- It is performed by a router (or similar device) that modifies the source or destination IP address in IP packet headers as they pass through.
- Besides conserving public IP addresses, NAT adds a layer of security by hiding the internal network structure.

## Private vs. Public IP Addresses

- Public IP addresses are globally unique, assigned by ISPs, and reachable from anywhere on the internet (e.g., 8.8.8.8 for Google's DNS server).
- Private IP addresses are used within local networks and are not routable on the global internet; internet backbone routers do not forward packets to them.
- RFC 1918 defines common private IPv4 ranges: 10.0.0.0–10.255.255.255, 172.16.0.0–172.31.255.255, and 192.168.0.0–192.168.255.255.
- Private IPs conserve public address space and isolate internal devices from direct exposure to external threats.

## How NAT Works

- Devices on a home network (e.g., laptop, smartphone, gaming console) each have a unique private IP address.
- The router has a LAN interface (private IP) and a WAN interface (public IP assigned by the ISP).
- When a device sends a request, the router's NAT function replaces the private source IP with its public IP before forwarding the packet to the internet.
- The router's NAT table tracks IP/port mappings so that incoming responses are translated back to the correct private IP and forwarded to the originating device.

## Types of NAT

- Static NAT: a one-to-one mapping between a private IP address and a public IP address.
- Dynamic NAT: assigns a public IP from a pool of available addresses to a private IP as needed.
- Port Address Translation (PAT/NAT Overload): the most common form, letting multiple private IPs share one public IP by distinguishing connections via unique port numbers.

## Benefits and Trade-Offs

- Benefits: conserves the limited IPv4 address space, provides a basic layer of security by not exposing internal network structure, and offers flexibility for internal IP addressing schemes.
- Trade-offs: hosting public servers behind NAT requires extra configuration (e.g., port forwarding), NAT can break protocols relying on end-to-end connectivity, and it adds complexity to troubleshooting.

## Acronyms

- **NAT**: Network Address Translation
- **PAT**: Port Address Translation
- **LAN**: Local Area Network
- **WAN**: Wide Area Network
- **ISP**: Internet Service Provider
- **RFC**: Request for Comments
- **IETF**: Internet Engineering Task Force

## Definitions

- **RFC 1918** is an IETF standard from February 1996 that sets aside specific IPv4 address blocks for private local area networks. These private IP addresses are not routed on the public internet, helping conserve remaining IPv4 address space through Network Address Translation (NAT).
- **Internet backbone routers**, also known as **core routers**, are ultra-high-capacity hardware devices that forward data packets at speeds of 100 Gbps or more. They form the core infrastructure of the global internet by routing massive volumes of international and domestic traffic across a decentralized mesh of fiber-optic lines.
- **Port forwarding** is a router setting that lets outside devices on the internet connect to a specific device inside your private home network. By default, your router blocks incoming traffic for safety. Port forwarding opens a specific "door" (port) and sends that traffic to the correct local IP address.

## Q&A – Questions and Answers

**Q: What type of NAT allows multiple private IP addresses to share one public IP address using unique port numbers?**

**A**: PAT

**Q: What RFC specifies private IP ranges?**

**A**: RFC 1918

**Q: Which NAT type involves a one-to-one mapping of private IP addresses to public IP addresses?**

**A**: Static NAT

**Q: What type of NAT assigns a public IP from a pool as needed?**

**A**: Dynamic NAT

**Q: What device typically performs NAT in a home network?**

**A**: Router
